# 💘 Lip贝叶斯Dating模型

> *"如果一段关系可以用概率追踪，你现在的胜率是多少？"*

用贝叶斯定理 + 逻辑回归，把暧昧不明的 situationship 变成可计算、可追踪、可更新的概率系统。每次约会、每句对话、每个信号，都是更新你对这段关系判断的证据。

## 一句话概括

你把每次互动当成一个**似然比（Bayes Factor）**输入模型，它告诉你：**基于目前所有证据，这段关系的成功概率是多少？**

## 核心公式

$$P_j^{(t)} = \sigma \left( \log \frac{P_{j0}}{1 - P_{j0}} + \sum_{i=1}^t w_i \log \frac{P(e_{ij}|H_j)}{P(e_{ij}|\neg H_j)} \right)$$

- $P_j^{(t)}$ — 经过 t 次互动后，关系成功的后验概率
- $P_{j0}$ — 你的初始判断（第一印象、眼缘、基础条件）
- $\frac{P(e|H)}{P(e|\neg H)}$ — 每个事件的似然比：这件事在"对的人"身上 vs "错的人"身上，谁身上更常见？
- $w_i$ — 权重：核心价值观 > 日常互动 > 模糊信号
- 同一公式切换假设 $H$，即可预测**适配度、破裂风险、挽回概率**

## 三种预测

| 预测目标 | 问法 | 示例场景 |
|---------|------|---------|
| 🔗 长期适配 | "我们到底合不合适？" | 约会第5次，不确定要不要确认关系 |
| 💔 情感破裂 | "是不是快分手了？" | 冷战三周，对方越来越冷淡 |
| 🔄 挽回成功 | "还有可能复合吗？" | 分手后对方偶尔点赞朋友圈 |

## 举个栗子

> 你刚认识一个人，第一印象不错，觉得适配概率大概 20%（先验）。
>
> 然后你观察到四个信号：
> - 对方主动分享了个人经历（BF=3，正面）
> - 你们聊到人生观很一致（BF=2，正面）
> - 对方约会后主动约下次（BF=1.5，正面）
> - 对方回复你消息很慢（BF=0.6，负面）
>
> 累积贝叶斯因子 = 3 × 2 × 1.5 × 0.6 = **5.4**
> 后验概率 = **57.4%**
>
> 从 20% 跳到 57.4%——信息改变了判断。

## 为什么不是纯朴素贝叶斯？

视频评论区很多人问：直接连乘不就行了？为什么需要权重 $w_i$？

因为"秒回消息"和"主动找话题"高度相关——它们都在反映"对方对你有兴趣"这**同一个底层维度**。朴素贝叶斯的连乘会把这个维度的信号重复计算，导致概率极端化（99% 或 1%）。

加入权重 $w_i$ 后，模型在数学上等价于**逻辑回归**，可以对共线信号降权，输出更稳健的概率估计。
