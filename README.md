# 💘 Lip贝叶斯Dating模型

> *"如果一段关系可以用概率追踪，你现在的胜率是多少？"*

把暧昧不明的 situationship 变成可追踪、可更新的概率系统。每次约会、每句对话、每个信号，都是更新判断的证据——你只需要凭直觉回答大/中/小，剩下的交给模型。

不用懂数学，会选大中小就行。

## 三种预测

| 预测目标 | 你问自己的问题 | 示例场景 |
|---------|-------------|---------|
| 🔗 长期适配 | "我们到底合不合适？" | 约会第5次，不确定要不要确认关系 |
| 💔 情感破裂 | "是不是快分了？" | 冷战三周，对方越来越冷淡 |
| 🔄 挽回成功 | "还能复合吗？" | 分手后对方偶尔点赞朋友圈 |

## 怎么用

打开 Claude Code，说 `/bayesian-dating`，然后：

1. 选一个预测目标（适配/破裂/挽回）
2. 凭直觉回答先验概率（大/中/小）
3. 一个个说你们之间的关键事件，每个事件选方向、强度、重要性
4. 模型在后台算，最后给你概率变化和一句话建议

全程不用填数字，选大中小就行。

## 举个栗子

> 你刚认识一个人，第一印象还行。聊了几次之后：
>
> - 对方主动分享个人经历 → 正面、强度中、重要性中
> - 聊到人生观很一致 → 正面、强度大、重要性大
> - 约会后对方主动约下次 → 正面、强度中、重要性中
> - 回复消息很慢 → 负面、强度小、重要性小
>
> 模型把这些信号综合后，你的适配概率从初始 50% 涨到 74%。
>
> 好坏信号各一半，数字不会骗你——但也别全信它。

## 数学原理

*以下内容给想深挖的人看，不看也不影响使用。*

### 核心公式

$$P_j^{(t)} = \sigma \left( \log \frac{P_{j0}}{1 - P_{j0}} + \sum_{i=1}^t w_i \log \frac{P(e_{ij}|H_j)}{P(e_{ij}|\neg H_j)} \right)$$

- $P_j^{(t)}$ — 经过 t 次互动后，关系成功的后验概率
- $P_{j0}$ — 先验概率（第一印象、基础条件）
- $\frac{P(e|H)}{P(e|\neg H)}$ — 似然比（Bayes Factor）：>1 支持适配，<1 反对
- $w_i$ — 事件权重：核心价值观 > 日常互动 > 模糊信号
- 同一公式切换假设 $H$，即可预测适配度、破裂风险、挽回概率


### 为什么不是纯朴素贝叶斯？

"秒回消息"和"主动找话题"高度相关——都在反映"对方有兴趣"这**同一个维度**。朴素贝叶斯连乘会重复计算，导致概率极端化（99% 或 1%）。

加入权重 $w_i$ 后，模型在数学上等价于**逻辑回归**，可以对共线信号降权，输出更稳健的概率。
