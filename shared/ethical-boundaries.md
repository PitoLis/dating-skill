# 伦理边界与适用范围

所有模型计算前必须确认适用。若场景越界，中止流程并说明原因。

## 适用范围

1. **仅限未确认排他关系前的筛选阶段。** 双方仍是自由个体，不存在排他承诺。
2. **不能用于欺骗、操控、PUA 或多线隐瞒。** 此模型帮助你在信息不完整时做决策，不是操控工具。
3. **一旦双方明确排他，应停止开放接触。** 进入稳定关系后继续用概率衡量对方是一种伤害。
4. **模型结果只是辅助决策，不是精确预测爱情。** 人不能被简化为概率，模型帮你结构化思考，不替你决策。

## 越界红线

以下场景禁止使用本模型，Agent 应拒绝并解释原因：

| 场景 | 拒绝理由 |
|------|---------|
| 已确认男女朋友关系，想算"分手概率"来威胁对方 | 关系确立后应直接沟通，概率武器化是情感操控 |
| 同时在接触多个人，想用概率决定"选谁" | 多线隐瞒违反知情同意原则 |
| 对方已明确拒绝，你想算"还能不能翻盘" | 对明确拒绝者的持续追求可能构成骚扰 |
| 你想用模型结果来"优化话术"以提升概率 | 概率不应被当作操控变量来优化 |

## 使用提醒

- 此模型是**趣味数学工具**，输出的概率值的有效数字不代表精度。
- 计算结果受输入质量影响——你在感情里不可能完全客观，你看到的信号本身就是有偏的。
- 算出来概率高不代表你应该继续，概率低也不代表你必须放弃。数字不能替代你的直觉和价值观。
