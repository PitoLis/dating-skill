# 默认行为信号参数表

供高级分析模式（compatibility-advanced）使用。每项信号包含：
- **BF**：Bayes Factor = P(e|H)/P(e|¬H)，>1 支持适配假设，<1 反对
- **w**：权重，控制该信号对 log-odds 的贡献。高级模式权重整体 ≤1.0，因为信号数量多、粒度细，避免共线性叠加导致概率极端化

若与简易模式（大/中/小）对比：简易模式事件少（3~8 条），权重范围 0.5~2.0；高级模式事件多（可达 10+ 条），权重范围 0.2~1.0，两者输出不可直接比较。

## 使用说明

- 同一底层维度的信号（如 #1 主动见面 + #4 主动聊天）同时录入时，各自 w 自动打 7 折以避免共线性
- #25、#26、#27 出现任一条时，无论计算概率多少，Agent 应给出明确的退出建议
- 信号权重整体偏保守（w ≤ 1.0），目的是在高粒度模式下避免概率快速极端化
- 若用户需自定义参数，Agent 应逐条询问 7 项参数（见 compatibility-advanced workflow）
