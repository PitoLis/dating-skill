# 权重参考表

跨模型共享的事件权重参考。适用于所有需要为不同事件类型分配权重 $w_i$ 的场景。

## 通用权重层级

| 层级 | 权重 w | 事件特征 |
|-----|--------|---------|
| 核心信号 | 2.0~3.0 | 直接反映假设核心的事件（价值观、重大决策行为） |
| 强信号 | 1.5~2.0 | 重要但非唯一的指标（冲突处理方式、情绪回应质量） |
| 常规信号 | 0.8~1.2 | 日常互动中的一般观察（聊天频率、约会体验） |
| 弱信号 | 0.4~0.7 | 间接或模糊的信号（社交圈反馈、朋友转述） |
| 噪声 | 0.1~0.3 | 高度模糊、易被曲解的信号（未证实的传言、单一表情包） |

## 共线性处理

以下事件对高度相关（共线性），应分别降低权重：

| 事件 A | 事件 B | 建议降权方式 |
|--------|--------|-------------|
| 秒回消息 | 主动找话题 | 各降为 0.6~0.7 |
| 送礼物 | 约会安排精心 | 各降为 0.7~0.8 |
| 朋友认可 | 家人认可 | 各降为 0.6~0.7 |
| 公开社交互动 | 私下分享日常 | 各降为 0.7~0.8 |

规则：如果两个事件本质上是同一底层态度（如"投入程度"）的不同表现，
同时录入时应降低各自权重，避免该维度被重复计算。
