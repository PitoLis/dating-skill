# 情感破裂风险评估

## 交互原则

- 每轮只问一个问题，不输出后台计算
- 事件结束前不展示概率

## 流程

### Step 1: 设定先验概率

```
不考虑具体事件，仅凭当前关系的整体感觉，
你觉得这段关系正在走向结束的概率大概是多少？
（建议保守起步，如 10%~20%）
```

### Step 2: 收集证据事件

每事件三问：

```
方向：这件事让你对这段关系的感觉是？
  [正面] / [中性] / [负面]

强度：这个感觉有多强？
  [大] / [中] / [小]

重要性：这件事判定关系有多关键？
  [大] / [中] / [小]
```

### 引导参考（Agent 内部使用）

帮用户校准判断：

| 事件 | 方向 | 强度建议 | 说明 |
|------|------|---------|------|
| 频繁冷战（每周+） | 负面 | 大 | 强负面信号 |
| 回避深度对话 | 负面 | 中~大 | 较强负面信号 |
| 减少见面/聊天频次 | 负面 | 中 | 中等负面信号 |
| 偶尔一次争吵 | 负面 | 小~中 | 弱信号，健康关系也常见 |
| 朋友说你们很好 | 正面 | 小~中 | 正向信号 |
| 对方主动解决问题 | 正面 | 中~大 | 正向信号 |

### Step 3: 遗漏提醒

当用户表示没有更多事件时，主动提醒回顾，
**正面和负面各举一半**，数据越多判断越准：

```
想再确认一下。数据越多判断越准，好信号坏信号都看看：

关系好的一面：
- 你们最近一次相处很舒服是什么时候？怎么回事？
- 她有什么让你觉得"这个人还是在乎我的"的行为？
- 朋友对你们关系的评价是什么？

关系危险的一面：
- 吵架之后通常怎么收场？冷战、敷衍道歉、还是真的解决问题？
- 她对你的态度有没有明显变化？从什么时候开始的？
- 你回想一下，这段关系里让你很累的瞬间有哪些？

有要补充的吗？
```

### Step 4: 结果输出

**概率极端时（<5% 或 >95%）**：不说教不分析，给一句共情的话，邀请补充更多信息。
**概率中间时**：简要说明关键推动事件和分档建议：
  - ≥60%：信号强烈，建议主动沟通或寻求关系咨询
  - 30%~60%：有风险，需要针对性改善
  - <30%：证据不足以支持破裂判断
