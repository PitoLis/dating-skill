# 贝叶斯概率更新模型

## 核心公式

$$P_j^{(t)} = \sigma \left( \log \frac{P_{j0}}{1 - P_{j0}} + \sum_{i=1}^t w_i \log \frac{P(e_{ij}|H_j)}{P(e_{ij}|\neg H_j)} \right)$$

## 参数定义

| 参数 | 含义 | 取值范围 |
|-----|------|---------|
| $P_j^{(t)}$ | t 次交互后关于假设 H_j 的后验概率 | 0~1 |
| $P_{j0}$ | 先验概率 | 0~1，保守建议 0.1~0.5 |
| $\sigma$ | Sigmoid: $\sigma(x) = 1/(1+e^{-x})$ | — |
| $e_{ij}$ | 第 i 次观察到的互动事件 | — |
| $H_j$ | 关于对象 j 的正向假设 | — |
| $\neg H_j$ | 反向假设 | — |
| $\frac{P(e_{ij}\|H_j)}{P(e_{ij}\|\neg H_j)}$ | 似然比（Bayes Factor） | >0；>1 支持 H，<1 支持 ¬H |
| $w_i$ | 事件权重 | 0.1~3.0，默认 1.0 |

## 三种预测：同一公式三种 H

| 预测目标 | $H_j$ 定义 |
|---------|-----------|
| 长期适配 | 两人是高度适配的长期伴侣 |
| 情感破裂 | 关系正在走向破裂 |
| 挽回成功 | 分手后可以成功复合 |

## 数学推导

### 朴素贝叶斯形式

贝叶斯定理赔率形式：

$$\frac{P(H|E)}{P(\neg H|E)} = \frac{P(H)}{P(\neg H)} \cdot \frac{P(E|H)}{P(E|\neg H)}$$

即：**后验赔率 = 先验赔率 × 贝叶斯因子**

### 多事件独立假设

$$O(H|E) = O(H) \cdot \prod_{i=1}^t \frac{P(e_i|H)}{P(e_i|\neg H)}$$

### 对数几率形式

$$\log O(H|E) = \log O(H) + \sum_{i=1}^t \log \frac{P(e_i|H)}{P(e_i|\neg H)}$$

### 加权修正（逻辑回归形式）

引入权重 $w_i$ 解决特征共线性（如"秒回消息"与"主动找话题"高度相关），
将乘法转换为加权加法：

$$\log O(H|E) = \log \frac{P_{j0}}{1 - P_{j0}} + \sum_{i=1}^t w_i \log \frac{P(e_{ij}|H_j)}{P(e_{ij}|\neg H_j)}$$

通过 Sigmoid 映射回概率空间。

### 数值示例

- 先验概率 $P(H) = 0.2$
- 四个独立信号，BF 分别为 3, 2, 1.5, 0.6

1. 先验赔率：$O(H) = 0.2/0.8 = 0.25$
2. 累积 BF：$3 × 2 × 1.5 × 0.6 = 5.4$
3. 后验赔率：$0.25 × 5.4 = 1.35$
4. 后验概率：$1.35/(1+1.35) = 57.4\%$

从 20% 更新到 57.4%——贝叶斯更新将四个信号的信息完全吸收。
