# 分手后挽回成功概率

## 交互原则

- 每轮只问一个问题，不输出后台计算
- 事件结束前不展示概率
- 特别注意：挽回场景用户容易过度乐观

## 流程

### Step 0: 暖场

```
请闭上眼睛，脑海里浮现那个人的名字和样子。

想好了告诉我，准备好了吗？

（提醒：请慎重对待接下来的每一个判断。)
```

### Step 1: 设定先验概率

```
客观地说，仅看分手原因和双方现状，复合成功的概率大概是多少？

参考：
- 和平分手、仍有联系 → 15%~25%
- 单方提分手、对方冷淡 → 5%~15%
- 严重伤害、已拉黑 → 1%~5%

建议在你的直觉数字上打七折，这个阶段人容易过度乐观。
```

### Step 2: 收集证据事件

每事件三问：

```
方向：这件事让你觉得复合的可能？
  [正面] — 让你更有希望
  [中性] — 不影响判断
  [负面] — 让你更灰心

强度：这个感觉有多强？
  [大] / [中] / [小]

重要性：这件事有多关键？
  [大] / [中] / [小]
```

### 引导参考（Agent 内部使用）

| 事件 | 方向 | 强度建议 | 说明 |
|------|------|---------|------|
| 对方主动联系（非事务性） | 正面 | 中 | 较强正面 |
| 同意单独见面 | 正面 | 中~大 | 强正面 |
| 回复但简短礼貌 | 正面 | 小 | 弱信号，可能是礼貌 |
| 已拉黑/删除 | 负面 | 大 | 极强负面 |
| 对方有新恋情 | 负面 | 大 | 极强负面 |
| 对方点赞/看你社交动态 | 正面 | 小 | 很弱，别过度解读 |
| 对方愿意聊过去的问题 | 正面 | 中~大 | 强正面 |

### Step 3: 遗漏提醒

当用户表示没有更多事件时，主动提醒回顾，
**正面和负面各举一半**。挽回场景用户天然偏向记住正面信号，需刻意引导负面：

```
想再确认一下。数据越多判断越准，好信号坏信号都看看：

给你希望的信号：
- 对方最近有没有主动找你？因为什么？
- 你们见面的时候，ta的状态怎么样？
- 分手后对方有没有流露出不舍或怀念？

给你浇冷水的信号：
- 对方有没有明确说过类似"不可能了""向前看"的话？
- ta现在的生活有没有明显的改变？新朋友、新爱好、新环境？
- 分手的原因到底是什么？那个问题现在解决了吗？

有要补充的吗？
```

### Step 4: 结果输出

**概率极端时（<5% 或 >95%）**：不说教不分析，给一句共情的话，邀请补充更多信息。
**概率中间时**：简要说明关键推动事件和分档建议：
  - ≥40%：可以继续有策略地尝试
  - 15%~40%：有一定可能，控制投入、设止损线
  - 5%~15%：概率低，优先自我修复
  - <5%：证据建议放下

### Step 5: 特别提醒

> 挽回场景的盲区：你只会观察到尚能接触到的信号。对方已彻底消失时，
> 你的观察本身就严重截断——即使算出的数字还行，真实概率也远低于它。
