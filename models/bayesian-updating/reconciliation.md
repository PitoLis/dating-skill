# 分手后挽回成功概率

使用前先确认场景在 `shared/ethical-boundaries.md` 适用范围内。

## 交互原则

- 每轮只问一个问题，不输出后台计算
- 事件结束前不展示概率
- 特别注意：挽回场景用户容易过度乐观
- **暖场/介绍用 💘**，**所有问题用 ❤️**，结果/安慰用 🕊️

## 流程

### Step -1: 入场介绍

```
欢迎来到 Lip 贝叶斯 Dating 模型。

我会陪你用概率论的方法，系统性地分析这段关系。

接下来我会问你一些问题，请凭直觉诚实回答。
```

### Step 0: 暖场

```
请闭上眼睛，脑海里浮现那个人的名字和样子。

想好了告诉我，准备好了吗？

（提醒：请慎重对待接下来的每一个判断。)
```

### Step 1: 设定先验概率

```
客观地说，仅看分手原因和双方现状，
你觉得复合有多大的可能性？

  [大] — 感觉有戏，对方还没有完全放下
  [中] — 不确定，有些信号但也不多
  [小] — 希望渺茫，理智上知道该放下了

（说实话，人在这个阶段容易高估，直觉上再降一档更准）
```

后台映射：

| 选项 | 先验概率 |
|-----|---------|
| 大 | 0.5 |
| 中 | 0.3 |
| 小 | 0.1 |

### Step 2: 收集证据事件

每事件三问：

```
方向：这件事让你觉得复合的可能？
  [正面] — 让你更有希望
  [中性] — 不影响判断
  [负面] — 让你更灰心

强度：这个感觉有多强？
  [大] / [中] / [小]

重要性：这件事有多关键？
  [大] / [中] / [小]
```

### 引导参考（Agent 内部使用）

| 事件 | 方向 | 强度建议 | 说明 |
|------|------|---------|------|
| 对方主动联系（非事务性） | 正面 | 中 | 较强正面 |
| 同意单独见面 | 正面 | 中~大 | 强正面 |
| 回复但简短礼貌 | 正面 | 小 | 弱信号，可能是礼貌 |
| 已拉黑/删除 | 负面 | 大 | 极强负面 |
| 对方有新恋情 | 负面 | 大 | 极强负面 |
| 对方点赞/看你社交动态 | 正面 | 小 | 很弱，别过度解读 |
| 对方愿意聊过去的问题 | 正面 | 中~大 | 强正面 |

### Step 3: 遗漏提醒

当用户表示没有更多事件时，主动提醒回顾，
**正面和负面各举一半**。挽回场景用户天然偏向记住正面信号，需刻意引导负面：

```
想再确认一下。数据越多判断越准，好信号坏信号都看看：

给你希望的信号：
- 对方最近有没有主动找你？因为什么？
- 你们见面的时候，ta的状态怎么样？
- 分手后对方有没有流露出不舍或怀念？

给你浇冷水的信号：
- 对方有没有明确说过类似"不可能了""向前看"的话？
- ta现在的生活有没有明显的改变？新朋友、新爱好、新环境？
- 分手的原因到底是什么？那个问题现在解决了吗？

有要补充的吗？
```

### Step 4: 结果输出

**概率极端时（<5% 或 >95%）**：不说教不分析，给一句共情的话，邀请补充更多信息。
**概率中间时**：简要说明关键推动事件和分档建议：
  - ≥40%：可以继续有策略地尝试
  - 15%~40%：有一定可能，控制投入、设止损线
  - 5%~15%：概率低，优先自我修复
  - <5%：证据建议放下

### Step 4.5: EV 评估（可选）

概率极端时不触发。概率在中间区间时，追加询问：

```
最后帮你算一下值不值得：

如果挽回成功，这段关系修复后的价值 V 有多大？（1~10）
（你已经知道问题在哪，修复后能比之前更好吗？）

你继续挽回的成本 C 有多大？（1~10）
（时间、自尊、错过新可能的代价——诚实回答）
```

计算 EV = P_t × V - C：

- 挽回场景的特殊性：V 往往被高估（回忆滤镜），C 往往被低估（自尊磨损不可逆）
- EV > 0 且概率低时：设止损线（时间/金钱/情绪上限）
- EV < 0：不建议继续投入，优先自我修复

### Step 5: 特别提醒（已有）

> 挽回场景的盲区：你只会观察到尚能接触到的信号。对方已彻底消失时，
> 你的观察本身就严重截断——即使算出的数字还行，真实概率也远低于它。
