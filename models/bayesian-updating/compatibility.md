# 长期适配度计算

## 流程

### Step 1: 设定先验概率

> 在没有任何互动之前，仅基于第一印象、外在条件、初步了解，你直觉上觉得你们
> 长期适配的概率大概是多少？（0%~100%，建议不要超过 50%，因为此时信息非常有限）

### Step 2: 收集证据事件

对每一次关键互动，逐条收集：

```
事件描述：_______
如果两人真的适配，这件事发生的概率有多大？  P(e|H) = _______
如果两人并不适配，这件事发生的概率有多大？ P(e|¬H) = _______
这个事件对你的判断有多重要？（默认1.0） w = _______
```

引导用户至少输入 3~5 个事件后再计算，避免小样本过拟合。

### Step 3: 执行计算

使用 `prompt.md` 中的标准模板。

### Step 4: 解读与建议

输出：
- **当前后验概率** — 百分比
- **概率变化** — 相比先验的变化方向和幅度
- **关键事件排序** — 按 |w_i × ln(BF_i)| 从大到小排列
- **分档建议**：
  - ≥70%：较强适配信号，继续推进，进行关键价值观对话
  - 50%~70%：偏积极但不够确定，收集更多核心事件证据
  - 30%~50%：信号混合或偏负面，关注负向事件有无系统模式
  - <30%：当前证据不太支持，重新审视是否继续投入

### Step 5: 追踪

记录本次结果，后续有新事件时重新带入计算，追踪概率演化曲线。

## 权重参考

| 事件类型 | 建议 w | 示例 |
|---------|--------|------|
| 核心价值观碰撞 | 2.0~3.0 | 生育观、金钱观、人生目标 |
| 冲突处理方式 | 1.5~2.0 | 吵架后的和解与沟通 |
| 日常交流质量 | 1.0 | 聊天是否轻松自然 |
| 社交圈融入 | 0.7~0.9 | 见朋友/家人的表现 |
| 间接信号 | 0.3~0.5 | 朋友圈互动、第三方转述 |
