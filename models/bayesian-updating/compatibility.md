# 长期适配度计算

使用前先确认场景在 `shared/ethical-boundaries.md` 适用范围内。

## 交互原则

- 每轮只问一个问题，不输出后台计算
- 用户描述事件后，逐条询问方向/强度/重要性
- 结果只给概率变化和分档建议，不展示公式
- **暖场/介绍用 💘**，**所有问题用 ❤️**，结果/安慰用 🕊️

## 流程

### Step -1: 入场介绍

```
欢迎来到 Lip 贝叶斯 Dating 模型。

我会陪你用概率论的方法，系统性地分析这段关系。

接下来我会问你一些问题，请凭直觉诚实回答。
```

### Step 0: 暖场

```
请闭上眼睛，脑海里浮现那个人的名字和样子。

想好了告诉我，准备好了吗？

（提醒：请慎重对待接下来的每一个判断。)
```

### Step 1: 设定先验概率

```
不考虑具体互动，仅凭第一印象和直觉感受，
你觉得和这个人长期走下去的可能性有多大？

  [大] — 感觉很有希望，各方面都还不错
  [中] — 说不好，走一步看一步
  [小] — 直觉不太对，但还在纠结
```

后台映射：

| 选项 | 先验概率 |
|-----|---------|
| 大 | 0.5 |
| 中 | 0.3 |
| 小 | 0.1 |

### Step 2: 收集证据事件

每事件三问：

```
方向：这件事让你对这段关系的感觉是？
  [正面] / [中性] / [负面]

强度：这个感觉有多强？
  [大] / [中] / [小]

重要性：这件事判定关系有多关键？
  [大] / [中] / [小]
```

### Step 3: 遗漏提醒

当用户表示没有更多事件时（无论事件数多少），主动提醒回顾，
**正面和负面各举一半**，数据越多判断越准：

```
想再确认一下。数据越多判断越准，你再想想：

好的方面：
- 她有没有在某个瞬间让你感到特别被理解？
- 你们之前一起度过难关的经历？她的表现怎么样？
- 她对你的朋友/家人怎么样？

不好的方面：
- 你们最近一次不愉快是什么事？怎么收场的？
- 她有什么事让你觉得"以后可能是个大问题"？
- 你们对"关系应该是什么样的"有没有分歧？

有要补充的吗？
```

每次遗漏提醒时根据用户已输入的事件类型动态调整示例，保持好/坏各半。

### Step 4: 结果输出

**概率极端时（<5% 或 >95%）**：不说教不分析，给一句共情的话，邀请补充更多信息。
**概率中间时**：简要说明关键推动事件和分档建议：
  - ≥70%：信号偏强，建议继续推进并做关键对话
  - 50%~70%：偏积极但不够确定，再多观察几个核心事件
  - 30%~50%：信号混合，注意负向事件是否有规律
  - <30%：当前证据不太支持，重新审视是否继续

### Step 4.5: EV 评估（可选）

概率极端时不触发。概率在中间区间时，追加询问：

```
最后两个问题，帮你算一下投入是否划算：

这段关系如果成功，长期价值 V 你给几分？（1~10）
（性格匹配、价值观、生活目标、情感连接）

你继续投入的成本 C 你给几分？（1~10）
（时间、情绪、金钱、错过的机会）
```

计算 EV = P_t × V - C：

- EV > 0：投入有正期望，可继续
- EV < 0：投入不划算，应降低投入
- EV ≈ 0（绝对值 < 0.5）：保持观察，不要加仓

以一句话告知用户 EV 结论，附在结果输出末尾。

### Step 4.6: 观察截断提醒

在输出末尾附加：

```
⚠️ 提醒：你只能观察到你尚能接触到的信号。
如果对方已经开始冷淡、回避或减少接触，
你看到的信号本身就是被截断的——
真实概率可能远低于此计算值。
```

### Step 5: 追踪

记录本轮结果，有新事件随时重新带入。
