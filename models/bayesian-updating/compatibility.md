# 长期适配度计算

## 交互原则

- 每轮只问一个问题，不输出后台计算
- 用户描述事件后，逐条询问方向/强度/重要性
- 结果只给概率变化和分档建议，不展示公式

## 流程

### Step 1: 设定先验概率

```
在没有任何互动之前，仅基于第一印象、外在条件、初步了解，
你直觉上觉得长期适配的概率大概是多少？
（建议不超过 50%）
```

### Step 2: 收集证据事件

每事件三问：

```
方向：这件事让你对这段关系的感觉是？
  [正面] / [中性] / [负面]

强度：这个感觉有多强？
  [大] / [中] / [小]

重要性：这件事判定关系有多关键？
  [大] / [中] / [小]
```

### Step 3: 遗漏提醒

当用户表示没有更多事件，且当前事件数 ≤ 3 或概率极端（<5% 或 >95%）时，
主动提醒用户回顾可能遗漏的高影响事件：

```
目前信息还比较少，结果可能不够稳定。

你可以再想想这些方面有没有遗漏的信号：

- 吵架时的模式？是冷战、激烈争吵、还是能冷静沟通？
- 对方对你低谷时的态度？回避还是陪伴？
- 你们在金钱观上的具体差异？消费习惯、储蓄倾向？
- 对方怎么对待身边的人？服务员、朋友、家人？
- 你和她在一起时，精力是被消耗还是被补充？
- 对方有没有做过让你意外感动或失望的事？
- 关于未来的话题聊过吗？城市选择、职业规划、要不要小孩？

有需要补充的吗？
```

### Step 4: 执行计算

后台计算后验概率。向用户输出：
- 概率变化（先验 → 后验）
- 最关键的推动事件
- 分档建议

### Step 5: 追踪

记录本轮结果，有新事件随时重新带入。
